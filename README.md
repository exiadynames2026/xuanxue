# 八字排盘 & 铁板神数 · 四柱命理工具

纯前端、零依赖部署的八字（四柱命理）与铁板神数推演工具。

## 工具一：八字排盘（[index.html](index.html)）

### 功能

- **四柱八字**：年、月、日、时柱天干地支，含十神、藏干十神、纳音、星运（日主十二长生）、自坐、旬空
- **节气精确**：基于天文算法计算节气（lunar-javascript 内核），节气边界精确到分钟，年柱以立春切换、月柱以节切换
- **大运 · 流年**：阳年男顺/女逆排运，起运时间精确到天（3 天折 1 年），点击任一大运展开该步 10 个流年
- **真太阳时校正**：内置 110+ 城市经度，经度差 + 均时差（Spencer 公式）双重校正，可跨日自动处理
- **神煞**：天乙贵人、文昌、禄神、羊刃、金舆、驿马、桃花、华盖、将星、劫煞、灾煞、红鸾、天喜、孤辰、寡宿、天德、月德、魁罡、阴差阳错、十恶大败共 20 种
- **五行统计**：金木水火土按干支与藏干个数统计，百分比条形图
- **命宫 · 胎元 · 身宫** + 日主强弱简化评分（得令/得地/得势）
- **农历输入**：支持农历生日与闰月，自动转换公历
- **子时流派**：晚子时（23:00 后）日柱算当天/算明天两种口径可选

## 使用

无需构建、无需后端，三种方式任选：

1. **直接打开**：双击 `index.html`（所有依赖已内置于仓库）
2. **本地服务**：`npx serve .` 或任意静态服务器
3. **GitHub Pages**：仓库 Settings → Pages → 选择 main 分支根目录，即可获得在线地址

运行测试（Node ≥ 14）：

```bash
node test/verify.js         # 八字排盘 37 项
node test/tieban-verify.js  # 铁板神数 37 项
```

## 工具二：铁板神数（[tieban.html](tieban.html)）

按公开可考体系完整实现"**河洛起卦 → 考时定刻 → 按数取条文**"推演框架：

- **河洛起卦**：四柱天干/地支太玄数求和 → 先天八卦 → 本卦、变卦、互卦、错卦、综卦，卦画可视化（动爻高亮），每卦配断语
- **考时定刻**：一时辰分八刻，每刻各取一条父母类条文（含父母生肖标签），对照真实六亲锁定"真刻"——铁板神数标志性的考刻流程
- **条文断**：八类（父母/兄弟/婚姻/子女/性情/财帛/事业/运程）共 220+ 条铁板风格示例条文，锁定刻分后按公开取数式输出
- **大限流年**：八步大限卦轮（本→变→互→错→综→变互→变错→变综）配十年运程条文；未来十二年流年干支与条文
- **起例说明**：太玄数表、起卦式、动爻式、取数式、大限卦轮、考刻流程全部在页面内完整公开；同盘同刻同问恒取同条，完全确定

> ⚠️ 铁板神数真传加则与万二千条条文历来秘传，世上不存在"标准铁板算法"。本工具条文为**自撰示例库**（风格仿铁板），用于完整演示推演流程；持有师传条文库者可替换 `tieban-tiaowen.js` 套用本引擎。仅供传统文化学习与娱乐。

`test/tieban-verify.js` 含 37 项断言（太玄数表、8×8 卦名表、通行卦序、**河洛起卦手算对轴**：庚午/辛巳/癸巳/戊午盘 → 天数25 地数26 → 天泽履三爻动变乾、互睽、错谦、综小畜；取数确定性与考刻八刻条文互异性等）。

## 项目结构

```
├── index.html          # 八字排盘应用（界面 + 算法）
├── lunar.js            # lunar-javascript 历法内核（MIT License）
├── tieban.html         # 铁板神数 · 河洛考刻断
├── tieban-core.js      # 铁板核心算法（河洛起卦/卦变/取数，浏览器与 Node 双端通用）
├── tieban-tiaowen.js   # 铁板示例条文库 + 六十四卦断语 + 太玄数/卦名/卦序表
└── test/
    ├── verify.js        # 八字排盘 37 项准确性验证
    └── tieban-verify.js # 铁板神数 37 项验证（含手算对轴）
```

## 技术说明

- 历法内核 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT License），作者 6tail
- 真太阳时 = 北京时间 + (当地经度 − 120°) × 4 分钟 + 均时差（Spencer 1971 公式，精度约 ±0.5 分钟）
- 十神、藏干、纳音、十二长生、大运遵循《渊海子平》《三命通会》通行口径
- 铁板神数起卦体系：太玄数（扬雄《太玄》/大六壬通行口径）+ 河洛理数起卦 + 先天八卦；条文取数式见 tieban.html「起例说明」
